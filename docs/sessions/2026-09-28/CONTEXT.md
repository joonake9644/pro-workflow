- **센서는 AI·네트워크를 쓰지 않는다** — 결정론적이어야 재현이 된다. 그래서 LLM 판정은
  센서 밖(독립 리뷰)으로 뺐다.

  줄은 `파일:줄 + 면제된 경로`를 성공 출력에 노출한다. 면제를 경로 은닉에 쓸 수 없게 한 장치다.
- **완료 증거는 산출물 모양만 요구한다** — `lifecycle: complete`는 200B 이상 + 명령/결과 인용을
  요구하지만 HEAD 커밋 연결은 하지 않는다(#016). 가짜 증거("done" 한 단어)는 실패한다.
- **pre-commit 훅은 연결하지 않았다** — 이 클론은 `core.hooksPath` 미설정이고 `commit-validate.js`는
  opt-in(`setup-hook.js`) 구조다. CI만 게이트로 썼다. 로컬 커밋 전 게이트가 필요하면
  `npm run verify`를 직접 돌린다.

## 주의사항
- **node를 전환하면 `npm rebuild better-sqlite3`가 필요하다.** 네이티브 바인딩은 단일 ABI로만
  빌드된다. 전환 직후 테스트가 로드 실패로 수십 건 깨지면 테스트 결함이 아니다. **15분 넘 걸린다.**
- **`initializeDatabase`는 dbPath와 무관하게 매번 `~/.pro-workflow`를 만든다.** 테스트 격리에도
  부작용이므로, 부작용 없이 격리하려면 `:memory:`를 쓴다. 파일 DB를 쓸 땐 상위 디렉터리를
  스스로 만들어야 하고 teardown에서 `.db`·`-wal`·`-shm` 셋을 지워야 한다.
- **`createStore`는 `.map()`에 `typeof state[field]`가 아니라 전용 판정기를 쓴다.** `typeof`은
  `null`과 배열을 모두 `'object'`로 반환해 STATE 전체 검증이 통째로 건너뛰어진다(한때 그랬다).
- **변조(mutant) 통과를 "커버리지"로 보고하지 않는다.** 손으로 고른 목록은 지표가 아니다.
- 리뷰 프로세스는 권한 거부나 도구 실패로 **중간에 끊길 수 있다.** 완료 리포트가 실제로 나왔는지
  확인하기 전까지는 "리뷰 완료"로 취급하지 않는다.
